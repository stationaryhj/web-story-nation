# Q&A: 크롬 탭에 '스토리네이션'이 계속 노출되는 문제 (2026-07-27)

## 질문
서비스명을 '러브챗'으로 변경했는데 크롬 탭 제목에 여전히 '스토리네이션'으로 노출된다.

## 확인 결과
- 타이틀 정의는 `app/layout.tsx`의 `metadata.title` 한 곳뿐이며 '러브챗'으로 변경 완료 상태.
- 런타임에 `document.title`을 덮어쓰는 코드 없음 (전체 grep 확인).
- 로컬 개발 서버(localhost:3000) 응답 확인: `<title>러브챗</title>` 정상.

## 결론 — 코드 문제 아님, 캐시/미배포
1. **탭 미새로고침**: 탭 제목은 페이지 재로드 전까지 유지됨 → Ctrl+Shift+R.
2. **배포 사이트 열람**: 변경이 로컬에만 있으므로 배포 도메인(storynation.co.kr 등)은 재배포 전까지 이전 타이틀.
3. **주소창 자동완성/북마크**: 크롬이 과거 방문 시점 제목을 캐시해 표시.
